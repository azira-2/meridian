# Meridian

An original fintech product website and interactive local dashboard demo, built with React, Vite, Three.js, React Three Fiber, GSAP, Framer Motion, and Lucide.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To create and serve a production build:

```sh
npm run build
npm run preview
```

## Demo behavior

Scroll through the hero or choose **Open interactive demo** to move the 3D camera into the laptop screen and reveal the dashboard. Return to the top to reverse the transition. The dashboard includes locally persisted sample transactions, virtual cards, notifications, theme selection, and a validated simulated transfer flow. All account values and operations are fictional; no real funds move.
